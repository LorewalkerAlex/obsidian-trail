# Design Reference Evidence

This directory contains supporting evidence used during Trail design calibration.

It is **not** a project authority layer. Canonical Trail answers remain in `docs/product.md`, `docs/domain.md`, `docs/data.md`, `docs/architecture.md`, `docs/ui.md`, `docs/ui-blueprints.md`, `docs/design-to-code-map.md`, and `docs/implementation.md` according to their existing responsibilities.

Reference material may explain why a visual calibration was chosen, but it must not silently redefine Trail Product, Domain, Data, Architecture, UI behavior, or ownership decisions.

Current reference sets:

- [`linear-visual/`](linear-visual/README.md) — official Linear visual references used by Stage 12B calibration.
